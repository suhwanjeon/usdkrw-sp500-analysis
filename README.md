# S&P 500 vs USD/KRW (2020~) Analysis

This project compares the S&P 500 Index and USD/KRW exchange rate since 2020.  
Data was collected using Python (pandas, yfinance) and visualized with matplotlib.

## Key Insights
- USD/KRW surged during market stress periods (e.g., 2022–2023), coinciding with S&P 500 corrections.
- Some synchronized movements between FX volatility and market instability were observed.
